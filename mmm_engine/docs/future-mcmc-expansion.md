# 将来拡張メモ：MCMC実装の検討タイミング

## 現状

Option B（ハイブリッドCI）を採用。BayesianRidgeの事後共分散（sigma_）からβのCIを解析的に導出し、ROI/CPAの95%信頼区間を追加計算コストほぼゼロで出力している。

## MCMCが必要になる閾値

| 判断軸 | 閾値目安 |
|:---|:---|
| 年間媒体費 | 2億円超 |
| 月次媒体費 | 1,500万円超 |
| チャネル数 | 8チャネル以上 |
| 説明相手 | CFO・役員・監査・IR |

## 実装方針（検討時の出発点）

**ライブラリ:** PyMC（Python-native MCMC、PyTensor backend）

**変更点:**
- `_fit_bayesian_ridge()` を PyMC モデルに置き換え
- λ / α / γ / β を全てMCMCで同時推定
- NUTS sampler（No U-Turn Sampler）で事後分布をサンプリング
- 速度が問題になる場合は ADVI（変分推論）で近似

**計算コスト:** 現状の20〜40倍（30分〜2時間/クライアント）

**得られるもの:**
- 全パラメータの真の事後分布
- ROI/CPAの真の95%信頼区間（現状のOption Bより1.5〜2倍広い、より正直な幅）
- 「幅の幅」＝パラメータ間の相関まで含めた不確実性

## 現状で対応できる範囲

年間媒体費2億円未満 × SMB〜ミドル層 → Option B CIで十分戦える。
「MCMC対応可能」はケイパビリティとして持ちつつ、具体的な大型案件が見えた時点で実装判断する。
